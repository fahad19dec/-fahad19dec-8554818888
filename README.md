# Welcome to streamlit

This is the app you get when you run `streamlit hello`, extracted as its own app.

Edit [Hello.py](./Hello.py) to customize this app to your heart's desire. ❤️

Check it out on [Streamlit Community Cloud](https://st-hello-app.streamlit.app/)

## Axe Stays

- [`axe-stays/`](./axe-stays): **Axe Stays**, an Expo (web, iOS, Android) stays app
  with full search filters, accounts, booking and trips.
  See [`axe-stays/README.md`](./axe-stays/README.md) to run it.
- [`admin/`](./admin): the **admin dashboard** (Next.js + shadcn/ui) for users, listings,
  bookings, reports and analytics. It shares the guest app's database, so changes
  show up in the app right away. See [`admin/README.md`](./admin/README.md).
